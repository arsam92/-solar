## 🤝 مشارکت

اگه ایده یا پیشنهادی داری:
1. Fork کن
2. Branch بساز (`git checkout -b feature/amazing`)
3. Commit کن (`git commit -m 'Add amazing feature'`)
4. Push کن (`git push origin feature/amazing`)
5. Pull Request بزن
